My current focus is Arrays.
The Array problems are organized into topic-based files:

Topics practiced:

- Find largest number
- Find smallest number
- Calculate sum
- Calculate average
- Count even numbers
- Count odd numbers
- Find maximum difference
- Find second largest element
- Find second smallest element
- Count positive and negative numbers
- Find frequency of an element

### 2. Array Searching

📁 `Arrays/02_array_searching.py`

Topics practiced:

- Linear search with position

- Check if an array is sorted
- Find duplicate elements
- Remove duplicates
- Move zeros to the end
- Rotate an array
